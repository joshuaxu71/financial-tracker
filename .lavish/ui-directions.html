Day Journal — Design Decisions

Addressing your four open questions with concrete proposals.

Q1

Week strip + infinite scroll — confusing?

Yes — two navigation systems for the same axis creates confusion. The week strip implies "tap a day to go there" while the scroll already does that. Drop the week strip.

Proposal
  • → Month label ("August 2026") at top — tap it to open a compact month/year picker modal for long jumps
  • → Scroll = primary nav. No week strip needed.
  • → Today floats to the top on first load; scrolling up reveals older days
  • → A "Today" pill appears when you've scrolled far enough to lose today from view
Q2

Hierarchical categories — how to handle?

Self-referential categories.parent_id — no separate table. A category with parent_id = NULL is a group; one with a parent_id set is a leaf. Timeline colors by parent (group); sub-category is the detail label.

Proposal
  • → Entry form: pick parent group first (chips), then child categories expand below
  • → Timeline dots use parent's color; label shows child category name
  • → Filter chips (Q4) filter by parent OR child — two levels
  • → DB: add parent_id + color to existing categories table — no schema additions
Living Expenses Personal Big Purchases Holiday
Q3

Insert between entries + custom ordering

created_at is for auditing only. Add a sort_order: real column (fractional indexing — insert between 1 and 2 by using 1.5).

Proposal
  • → Drag handle (⠿) on left of each row — long-press to drag within a day
  • → Insert affordance: tap the gap between two rows → inline entry form opens between them
  • → Sort resets when you drag: recalculate sort_order for affected rows only
  • → Spreadsheet grid entry already appends; reorder is a post-save action in the journal view
Q4

Category filter + replace week strip with month picker

Your instinct is right. A month picker + category filter chips use the top bar well without the week strip redundancy.

Proposal
  • → Row 1: "August 2026 ▾" (tap = month picker) + scroll position indicator
  • → Row 2: horizontal filter chips — [All] [Living] [Personal] [Holiday] + sub-category expansion on tap
  • → Filter chips are sticky below the month header while scrolling
  • → Filtering hides non-matching expense rows but keeps day headers visible (shows filtered total)
