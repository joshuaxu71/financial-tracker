Confirmed budget model

  • Placement: budgets live per-category in the Categories page. The Budget tab becomes a read-only overview/dashboard.
  • Independent budgets: groups and sub-categories each carry their own monthly budget number. No auto-summing of children.
  • Group ↔ leaves constraint: if a group budget is set and all its leaves have budgets, the leaves must sum exactly to the group budget. If only some leaves are set, they may sum to less than the group — the remaining amount is a shared pool for the unset leaves; no per-leaf budget is written for them (it's just a total, never explicitly calculated or stored per leaf).

Which placement do you want?

Group budget rollup — confirmed

Independent, with a soft constraint on children:

▸ Each category (group or leaf) stores its own monthly budget. No auto-sum.

▸ If a group budget is set and all leaves are set → leaves must sum exactly to group.

▸ If a group budget is set and only some leaves are set → set leaves may sum to less than group; the remainder is a shared pool for unset leaves (never split out per leaf, never stored on them).

▸ No group budget set → leaves are free, no constraint.

▸ Budgets are guides, not gates — they never block recording an expense.
