Finance Tracker — Sources, Currencies & Net Worth

You asked to add multiple sources (banks/accounts) with varying currencies. The key design question is how sources relate to the expenses you already track. Three directions below — annotate or pick one.

A · Linked ledger Recommended

Every expense is attributed to a source. Each source has a name + currency. Balances are derived (opening balance + expenses). One coherent money picture.

How it works
  • • Track: each day sheet gets a source row selector (bank chip)
  • • Dashboard: spend per source + net worth card across sources
  • • Finance tab: source cards with balance, currency, conversion to base
  • • Model: sources(id, name, currency, sort_order) + expenses.source_id
Trade-offs · Expenses need a source (migrate existing rows to a default "Cash" source). Balances stay accurate automatically.

B · Balance tracker Light coupling

Sources are a standalone ledger of balances (opening balance + manual income/expense adjustments). The expense tracker stays untouched. Simplest, but two separate money pictures.

How it works
  • • Finance tab: add source with currency + starting balance
  • • Adjust: "balance +X" / "balance −X" entries per source
  • • Net worth: sum of converted balances
  • • Model: sources(id, name, currency) + source_entries(id, source_id, amount)
Trade-offs · No link to your category spend — you'd maintain balances by hand. Net worth only as accurate as your manual updates.

C · Full accounting Heavy

Sources, expenses, income, and transfers all in one double-entry-ish model. Balances always exact, transfers move money between sources, currencies convert at record time.

How it works
  • • Transfers: move money source→source (e.g. Wise → SMBC)
  • • Income: salary/deposits as negative expenses
  • • Model: expenses become transactions with source_id, kind (expense/income/transfer)
Trade-offs · Most powerful but a big redesign of Track, Dashboard, and Budget screens. Highest effort, more room for bugs.
